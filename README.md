## 🚀 À propos de moi

Je suis un développeur orienté backend, spécialisé dans la conception et le développement d’applications scalables avec **ASP.NET Web API**.

Je travaille principalement sur des systèmes métiers, notamment dans les domaines **administratif et financier**.
Mon approche repose sur une **architecture propre (Controller / Service / Repository)** afin de garantir la maintenabilité, la performance et l’évolutivité des applications.

---

## 🧠 Compétences clés

* Conception d’API RESTful
* Architecture logicielle (Clean Architecture)
* Modélisation de la logique métier
* Conception et optimisation de bases de données
* Développement Full-Stack (React / Next.js)
