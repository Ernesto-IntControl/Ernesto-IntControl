## 🚀 À propos de moi

Développeur orienté **backend**, spécialisé dans la conception d'applications **scalables** avec **ASP.NET Web API**.
Fondateur d'**INT GLOBAL SERVICES** (Kolwezi, RDC), je construis des systèmes métiers — principalement dans les domaines **administratif et financier** — pensés pour le marché local et régional.

Mon approche repose sur une **architecture propre (Controller / Service / Repository)** pour garantir maintenabilité, performance et évolutivité.
